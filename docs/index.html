Authority: 現在の canonical source of truth は src/data-format/schemas/*.schema.json です。v2-alpha.1 design の schema 文書は src/data-format/proposals/v2-alpha.1/schemas/ に proposal として分離し、同じ viewer で閲覧できるよう公開します。

ByteSequence model

Digests

生 bytes に直接適用した複数の fingerprint。例: SHA-1, SHA-256。Git blob OID のように framing を伴う外部識別子とは分離します。

Identifiers

ni:, swh: など外部体系で content を識別する URI。

Embedded bytes

document 自体が bytes を包含する場合。JSON では通常 Base64 で符号化します。

Locations

document 外に存在する bytes の URI-reference。HTTPS、相対 URI その他を許容できます。

Same content

inline、location、digest→CAS のどの経路で得ても、同じ byte sequence なら同一 content とみなします。

Thumbnail

保存方式ではなく ImageRepresentation.role = "thumbnail"。inline か外部化かは ByteSequence 側の選択です。
